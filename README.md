# My First Pipeline

Proyecto de demostración para aprender integración continua utilizando Git, GitHub y Jenkins.

## Descripción

Este proyecto contiene una pequeña aplicación Python con una función de suma y pruebas unitarias.

El objetivo es practicar un flujo básico de integración continua:

1. Desarrollo en VS Code.
2. Control de versiones con Git.
3. Publicación del código en GitHub.
4. Ejecución automática mediante Jenkins.
5. Build y pruebas unitarias.
